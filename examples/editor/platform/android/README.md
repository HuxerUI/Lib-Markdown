# Android Writer shell

This Gradle shell was generated by the HuxerUI CLI for `org.huxerui.markdown.editor`.
`huxerui package android` builds the same `markdown_editor` CMake target used on desktop.

## Release signing

Release builds use the fixed demo certificate at
`keystore/markdown-writer-release.jks` (alias `markdown-writer`, password
`markdown-writer-demo`). Override the `markdownWriterStorePassword`,
`markdownWriterKeyAlias`, and `markdownWriterKeyPassword` Gradle properties to sign with
a private keystore. The certificate SHA-256 is pinned in
`.github/workflows/release-writer.yml`; CI rejects APKs signed by another key.

Releases published before this fixed key (v0.2.4 and earlier) were signed with per-run
debug certificates. Uninstall that build once before installing an APK signed with this
key, since Android rejects updates with a different signing identity.

## Package

Run from `examples/editor`:

```sh
huxerui package android --profile release --optimization minsize --lto on --source /path/to/HuxerUI
```

The APK is written to `dist/android/app-release.apk`. Release builds use `c++_static`
and compress native libraries in the APK (`useLegacyPackaging = true`).
