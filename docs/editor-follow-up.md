# 编辑器后续讨论记录

记录日期：2026-11-06。按用户要求，非阻塞问题先记文档，当前交付不等待讨论。

## 已采用的实现选择

- SDK 增加通用 `TextField::TextStyles`，复用原生 attributed layout、选区、IME 和输入协议。
  当前接口由 [PR #153](https://github.com/HuxerUI/HuxerUI/pull/153) 提供；本库 CI 固定已审查的 PR 提交，
  没有直接修改 SDK 远端 main，等待作者审查合并。
- 当前 Markdown 以源码为持久表示；统一文档事务将跨段/块内语义标记转换为源码补丁。
  块内回退仍可每次编辑一个段落、标题或表格单元格。
  接受块内规范化、保留块外原始字节；不承诺全篇无损往返。
- 原有格式输入时保持。新输入的 Markdown 符号按字面字符保存；新增格式目前可使用源码工具栏。
- 无法验证往返的富文本修改报错并保留有效内容，结构修改可切回源码模式。
- 剧透默认视觉遮盖，点击/键盘链接激活/辅助功能 Activate 揭示；复制与辅助功能仍能读取正文。
  它是阅读体验，不用于保存秘密。揭示状态属于挂载段落，卸载或内容改变后重置。
- MD4C 当前 COLLAPSEWHITESPACE 对制表符开头的空白标记漏输出分隔；适配层在普通文本回调中
  做折叠，保留代码、公式、实体与原始坐标。已补制表符与流式/增量回归。
- 嵌套列表、引用、提示块、脚注正文与显式表格单元格接入原位编辑。MD4C 的本地位置回调提供原始偏移，
  写回前校验目标外的语法树。多行软换行可在编辑时规范为单行。硬换行及部分复杂容器使用块内源码输入。
- 右对齐单元格的末尾光标裁剪修复已合入 HuxerUI 官方 `main`。待验证同时包含 `TextStyles` 和光标修复的 SDK 后更新构建版本。
  [HuxerUI PR #152](https://github.com/HuxerUI/HuxerUI/pull/152)

## 下一轮值得确定的方向

1. 编辑事务与统一撤销：已将现有 `EditSession` 接入公共 `MarkdownEditor` 与 Writer，
   统一支持跨段选区、输入、格式、IME、Undo/Redo 和外部 Import；Writer 每标签历史独立保留。
   后续仍需扩展跨多个嵌套项替换和更完整的结构命令。
2. Enter/Backspace：统一文档路径已支持标题/正文拆段与合段，并纳入撤销历史。
   后续补列表续项、空项退出列表及更复杂嵌套结构的光标和虚拟滚动锚点；行内代码内换行仍拒绝。
3. 富文本格式工具栏：直接作用于显示选区；链接编辑需要区分改标签与改目标。
   当前已有链接保持目的地址，URL 外观改变只改标签。
4. Markdown 快捷输入：是否在空格/闭合标记时执行标题、列表、粗体等转换，以及如何撤销转换。
5. 结构编辑：扩展跨块选区、表格行列操作、列表标记和任务勾选切换，以及图片和脚注引用属性编辑。
6. 超长单段落性能：目前保留字符级语义数据，更新和序列化仍线性；需要真实文档基准后再选择
   run tree、rope 或持久事务结构，不把顶层虚拟化当作所有编辑工作的虚拟化。
7. SDK 分支合并/发布：所需接口由 [PR #153](https://github.com/HuxerUI/HuxerUI/pull/153)
   与 [PR #154](https://github.com/HuxerUI/HuxerUI/pull/154) 提供，官方 0.4.0 主线尚未包含。
   本库 CI 固定 fork `FarnaHerry/HuxerUI` 的 `farna/main` 提交 `062f3092`
   （已合并 upstream 0.4.0 与两项接口，不再 cherry-pick），待上游合并后切换为正式 SDK。

## MD4C 剩余能力边界

- superscript / subscript：语法存在，但 SDK 没有基线偏移属性。先补共享文字排版及各平台后端，
  再承诺原生上下标显示；暂不使用缩小但不移动基线的伪效果。
- 数学公式：已有 AST 与独占公式渲染入口；完整 TeX 排版后端和混排行内附件仍待选择。
- 原始 HTML：继续按字面文字显示；当前不引入 HTML 执行或网络资源加载。
- 自定义语法：优先独立 AST 后处理/渲染扩展；MD4C 无通用语法插件注册，不在第三方源码上堆补丁。
